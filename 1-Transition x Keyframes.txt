1-Transition x Keyframes
Transition (animação por estado)
A transição acontece quando algo muda de um estado para o outro.

.botao{
	background-color: blue;
	transition: background-color 0.5s ease;
}

.botão:hover{
	background-color: red;
}

Estado inicial: azul
estado final: vermelho
O navegador cria uma animação entre os dois estados

Keyframes (animação autônoma)
a animação acontece sozinha.

@keyframes piscar {
	from{
	opacity:1;
	}

	to {
	opacity: 0;
	}

transition: propriedade duração da curva;

ease

ease-out
-termina lento.
